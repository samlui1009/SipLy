# SipLy
<p>SipLy is an elevated personal project of my CPSC 210 academic project. The original application, which was build using Java/Java Swing and unit-tested with the JUnit Jupiter testing framework, was designed to allow users to track, log and analyze their daily beverage intakes. My original goal for developing this application was to help users be more mindful of their drinking habits, allowing users to analyze trends and habits across the day.</p>

<p>However, in order to better practice my full-stack development skills, I decided to augment and improve the Java application into a working web application.</p>

## Inspiration behind Project
<p>For more information behind the initial inspiration for the first iteration of SipLy, DailySips, please follow this link for DailySips' repository: https://github.com/samlui1009/DailySips</p>
